# content-manager

Content Manager is a Docker-based project with three main services:

- `backend` — FastAPI service for content schedules, topics, and draft management.
- `frontend` — Django-based admin UI for dashboard, topics, and schedules.
- `telegram` — Aiogram bot for admin interaction and scheduled posting.
- `database` — PostgreSQL storage for data.

## Architecture

- The backend exposes REST endpoints under `/content`.
- The frontend uses Django template views and calls the backend via `BACKEND_API_URL`.
- The Telegram bot uses `BACKEND_API_URL` and `SERVICE_ACCOUNT_TOKEN` to fetch drafts and schedules.
- Topics are generated by AI and can only be viewed or deleted through the frontend UI.

## Services

### backend

- Runs on port `8000`.
- Health endpoints:
  - `GET /` — backend status.
  - `GET /health/db` — database connection check.
- Swagger UI available at `/docs`.
- Uses SQLAlchemy and PostgreSQL.

### frontend

- Runs on port `8443`.
- Provides dashboard, topics, and schedules management pages.
- Dashboard shows backend and database health.
- Topics page allows viewing and deleting topics only.
- Schedules page allows creating, editing, and deleting schedules.

### telegram

- Uses Aiogram and OpenAI for draft generation and admin callbacks.
- Reads `BACKEND_API_URL` and `SERVICE_ACCOUNT_TOKEN` from environment.
- Supports Telegram commands:
  - `/start` — show welcome text and open WebApp button if configured.
  - `/ask <prompt>` — send prompt to OpenAI and return generated content.

## Environment variables

The following variables are used by the compose setup:

- `DB_USER` — PostgreSQL username (default: `postgres`).
- `DB_PASSWORD` — PostgreSQL password (default: `postgres`).
- `DB_NAME` — PostgreSQL database name (default: `content_manager`).
- `SERVICE_ACCOUNT_TOKEN` — token used by backend and frontend for service authentication.
- `SECRET_KEY` — backend secret key if required by the app.
- `BACKEND_API_URL` — frontend and telegram backend URL in Docker (`http://backend:8000`).
- `BOT_TOKEN` — Telegram bot token.
- `ADMINS` — comma-separated list of Telegram admin IDs.
- `OPENAI_API_KEY` — OpenAI API key for generating content drafts.
- `WEBAPP_URL` — public HTTPS URL for Telegram WebApp integration.

## Supported languages

- `ru` — Russian
- `en` — English
- `es` — Spanish

Language selection in the frontend is limited to these options.

## Run locally

```bash
docker compose up --build
```

Then open:

- Frontend: `https://localhost:8443`
- Backend API: `http://localhost:8000`

## Notes

- Topic creation is handled by AI; the UI only shows existing topics and allows deletion.
- The database health endpoint is used to display DB status on the dashboard only.
